## 🇧🇷 Português

> **Plataforma E-Commerce e Gerador de Cotação de Brindes Customizados B2B**

E-commerce B2B e simulador de propostas comerciais para brindes promocionais e presentes corporativos.

### 🚀 Principais Funcionalidades
- **Simulador de Orçamentos B2B**: Cálculo dinâmico de preços com descontos em lote, tipo de gravação e frete na hora.
- **Painel do Cliente**: Área logada para envio de logotipos/artes e acompanhamento das etapas de produção.
- **Grid Otimizado**: Carregamento veloz e assíncrono para catálogos volumosos de produtos.
- **Integração Comercial**: Exportação instantânea de PDFs de propostas e atalho direto para atendimento via WhatsApp.

### 🛠️ Tecnologias
- **Plataforma**: WordPress com customizações avançadas em Elementor Pro e WooCommerce.
- **Linguagens / Integração**: PHP, Custom JS, Vanilla CSS, WP REST API.

## 🇺🇸 English

> **B2B E-Commerce & Interactive Quote Customizer for Branded Gifts**

Online catalog and quote builder dashboard for custom corporate gifts and promotional products.

### 🚀 Key Features
- **Interactive Quote Calculator**: Calculates bulk pricing, branding types, and setup fees instantly.
- **Customer Assets Portal**: Upload area for logos/vectors and status tracking for product proofs.
- **Optimized Catalog Grid**: Dynamic, fast loading grid using lazy assets for massive product catalogs.
- **Sales Channel Integrations**: Auto-generates quotation PDFs and routes client queries to WhatsApp.

### 🛠️ Tech Stack
- **Platform**: WordPress, Elementor Pro, WooCommerce.
- **Languages / Integration**: PHP, Custom JS, Tailwind CSS, WP REST API.
